# יאללה English

אפליקציה ללימוד אנגלית לדוברי עברית: חיילים משוחררים, ילדים ומבוגרים.
שיעורים קצרים בסגנון משחק, סימולציות שיחה, קמע (סאבי, צבר עם כובע בלש) ומנוי חודשי.

## מה יש בפנים

- שאלון פתיחה שבונה מסלול אישי (מי לומד, מטרה, רמה, יעד יומי, פנייה בזכר או נקבה)
- 13 יחידות, 52 שיעורים: בסיס, הטיול הגדול, חיי היומיום, עבודה, ילדים, סלנג וטעויות של ישראלים
- הקלטות קול לכל מילה ומשפט (בתיקיית `audio`), נוצרות עם `tools/make_audio.py`
- כל שיעור: סצנה מונפשת עם שיחה, מילים חדשות, ותרגילים (בחירה, התאמת זוגות, בניית משפט, השלמה, הקשבה, כתיבה, דיבור)
- לבבות, נקודות XP, רצף ימים, יהלומים, הישגים, ליגה שבועית ומילון אישי
- יאללה פרימיום: 49 ₪ לחודש
- מצב בהיר וכהה, התקנה למסך הבית (PWA) ועבודה בלי אינטרנט

## הרצה

אין שלב בנייה. מגישים את התיקייה כאתר סטטי:

```bash
python3 -m http.server 8000
# ואז פותחים http://localhost:8000
```

להעלאה לאוויר מספיק כל אחסון סטטי (GitHub Pages, Netlify, Vercel, Cloudflare Pages).

## הגדרות: `js/config.js`

| הגדרה | מה היא עושה |
| --- | --- |
| `GOOGLE_CLIENT_ID` | מזהה OAuth מ-Google Cloud Console. כשהוא ריק, כפתור Google יוצר פרופיל מקומי בלבד |
| `PAYMENT_URL` | קישור לדף תשלום (PayPlus, Tranzila, Grow, Stripe). כשהוא ריק, ההצטרפות פותחת את פלוס במכשיר בלי חיוב |
| `PRICE_ILS` | מחיר המנוי החודשי |
| `TRIAL_DAYS` | ימי ניסיון חינם, 0 מבטל |
| `FREE_UNITS` | יחידות שפתוחות בחינם. בנוסף, השיעור הראשון בכל יחידה פתוח תמיד |

## מה עוד צריך כדי לעלות לאוויר עם לקוחות משלמים

ההתקדמות נשמרת כרגע בדפדפן של המשתמש (`localStorage`). כדי לגבות כסף אמיתי ולסנכרן בין מכשירים צריך שרת:

1. חשבונות משתמשים ושמירת התקדמות בענן
2. ספק סליקה שמודיע לשרת על תשלום, והשרת הוא שפותח את פלוס
3. ליגה אמיתית בין משתמשים (כרגע המתחרים מדומים)

## הוספת שיעורים

כל התוכן נמצא ב-`js/data.js`. שיעור הוא אובייקט עם מילים, משפטים ושיחה, והתרגילים נוצרים ממנו אוטומטית:

```js
{ t: 'בבית הקפה', e: '☕', who: '👩‍🍳',
  w: ['coffee|קפה|☕', ...],                       // 6 מילים: אנגלית|עברית|אימוג'י
  s: ['Can I have a coffee?|אפשר לקבל קפה?', ...],  // 4 משפטים
  d: ['a|Hi! What can I get you?|היי! מה להביא לך?', 'b|...'],  // שיחה: a הדמות, b הלומד
  tip: 'הטיפ של סאבי' }
```
